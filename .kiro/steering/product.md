# Product Overview

干细胞治疗档案管理系统 (Stem Cell Treatment Records Management System)

## Purpose
A medical records management system for stem cell treatment clinics, managing patient information, health assessments, treatment plans, and infusion schedules.

## Core Features
- **Customer Management**: Patient records with ID card as unique identifier
- **Health Data Entry**: Multi-department health assessment data (laboratory, imaging, general departments)
- **Stem Cell Treatment**: Treatment plan creation, scheduling, and record keeping
- **AI Health Assessment**: DeepSeek AI integration for generating professional health reports
- **AI Comparison Analysis**: Multi-exam comparison reports with trend analysis
- **PDF Generation**: Convert AI reports to PDF format
- **Statistics Dashboard**: Real-time business metrics and data visualization

## Key Business Rules
- All operations require customer profile creation first (customer-centric architecture)
- ID card number (身份证号) is the fundamental unique identifier across the system
- Health data is organized by department with dynamic configuration support
- Treatment plans support automatic disease type matching via keywords

## Target Users
- Medical staff managing stem cell treatment records
- Healthcare administrators tracking patient data
- Clinic managers monitoring treatment statistics

## Language
- All UI text, database schema, and documentation are in Chinese (中文)
- Code comments and technical documentation may be in English
